# Assignment 1: Hello World, Variables and Arithmetic

## 1. Experiment Title

Hello World, Variables and Arithmetic in Java.

## 2. Aim

To write Java programs to print text, declare and initialize variables of different data types, perform basic arithmetic operations, and calculate the area and perimeter of a circle using a constant.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. Output statements display text on the console. Variables store values in named memory locations. Java uses int, double, char, and String data types. Arithmetic operators perform addition, subtraction, multiplication, integer division, and modulus. The final keyword declares a constant. The area of a circle is PI × radius × radius, and its perimeter is 2 × PI × radius.


## 5. Algorithm / Procedure

### Question 1: Hello World

1. Start the program.

2. Create the Main class and define the main() method.

3. Print “Hello World”.

4. Print “Welcome to Java” on the next line.

5. Stop the program.



### Question 2: Variables

1. Start the program.

2. Declare and initialize an integer variable roll with 101.

3. Declare and initialize a double variable percentage with 84.5.

4. Declare and initialize a character variable section with 'B'.

5. Declare and initialize a String variable name with “Asha”.

6. Print all variable values with their labels.

7. Stop the program.



### Question 3: Arithmetic Operators

1. Start the program.

2. Declare two integer variables a = 17 and b = 5.

3. Calculate and display their sum, difference, product, quotient, and remainder using arithmetic operators.

4. Stop the program.



### Question 4: Constant and Circle Calculation

1. Start the program.

2. Declare the constant PI using final and initialize it with 3.14.

3. Declare radius = 7.

4. Calculate the area and perimeter of the circle.

5. Display both values up to two decimal places.

6. Stop the program.
