# Assignment 4: Methods, Factorial, Combinations and Permutations

## 1. Experiment Title

Methods, Factorial, Combinations and Permutations in Java.

## 2. Aim

To write Java programs using user-defined static methods to calculate combinations, permutations, and the larger of two numbers.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. A method is a reusable block of code that performs a specific task. Static methods can be called from the class without creating an object. A factorial is the product of all positive integers up to a number. Combination is calculated using nCr = n! / (r! × (n-r)!), while permutation is calculated using nPr = n! / (n-r)!. A method can accept parameters and return a value.


## 5. Algorithm / Procedure

### Question 1: Combination Using a Method

1. Start the program.

2. Define a factorial method that multiplies integers from 1 to n.

3. Define an nCr method using the factorial method.

4. Calculate 5C2 and display the result.

5. Stop the program.



### Question 2: Permutation Using a Method

1. Start the program.

2. Define a factorial method that multiplies integers from 1 to n.

3. Define an nPr method using the factorial method.

4. Calculate 5P2 and display the result.

5. Stop the program.



### Question 3: Finding the Larger of Two Numbers

1. Start the program.

2. Define a method maxOf() that accepts two integers.

3. Compare the two values and return the larger value.

4. Call the method with 14 and 9 and display the result.

5. Stop the program.
