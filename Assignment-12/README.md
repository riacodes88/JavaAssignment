# Assignment 12: Insertion Sort

## 1. Experiment Title

Insertion Sort in Java.

## 2. Aim

To write Java programs using Insertion Sort to arrange arrays in ascending order and count the number of shifts performed during sorting.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. Insertion Sort builds a sorted portion of an array one element at a time. Each new element is stored as a key and compared with elements before it. Larger elements are shifted one position to the right until the correct position for the key is found. The number of shifts can be counted during this process.


## 5. Algorithm / Procedure

### Question 1: Insertion Sort on an Array

1. Start the program.

2. Initialize the array with 7, 3, 5, and 1.

3. Select each element from the second position as the key.

4. Shift larger elements to the right and insert the key at its correct position.

5. Display the sorted array.

6. Stop the program.



### Question 2: Insertion Sort on Another Array

1. Start the program.

2. Initialize the array with 14, 3, 9, 21, and 6.

3. Apply Insertion Sort by shifting larger elements to the right.

4. Insert each key at its correct position.

5. Display the sorted array.

6. Stop the program.



### Question 3: Counting Shifts in Insertion Sort

1. Start the program.

2. Initialize the array with 6, 5, 4, 3, 2, and 1 and set shifts to 0.

3. Perform Insertion Sort.

4. Increment shifts whenever an element is moved one position to the right.

5. Display the total number of shifts.

6. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
Array = {7, 3, 5, 1}.


### Question 2:
Array = {14, 3, 9, 21, 6}.


### Question 3:
Array = {6, 5, 4, 3, 2, 1}.


## 7. Output

### Question 1:
```text
Sorted: [1, 3, 5, 7]
```


### Question 2:
```text
Sorted: [3, 6, 9, 14, 21]
```


### Question 3:
```text
Shifts: 15
```
