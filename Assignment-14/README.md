# Assignment 14: String Character Operations

## 1. Experiment Title

String Character Operations in Java.

## 2. Aim

To write Java programs to count vowels in a string, count occurrences of a specified character, and display each character with its index.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. A string contains a sequence of characters and can be traversed using a loop. The charAt() method returns the character at a given index, and length() returns the number of characters. A counter variable can be incremented when a character satisfies a condition. Vowels are a, e, i, o, and u.


## 5. Algorithm / Procedure

### Question 1: Counting Vowels

1. Start the program.

2. Initialize string s with “programming” and vowels with 0.

3. Traverse each character using its index.

4. If the character is a lowercase vowel, increment vowels.

5. Display the vowel count.

6. Stop the program.



### Question 2: Counting Occurrences of a Character

1. Start the program.

2. Initialize string s with “programming” and count with 0.

3. Traverse each character in the string.

4. Increment count whenever the character is 'g'.

5. Display the count of 'g'.

6. Stop the program.



### Question 3: Displaying Characters with Index

1. Start the program.

2. Initialize string s with “hello”.

3. Traverse the string using its index.

4. Display each index and its corresponding character.

5. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
s = "programming".


### Question 2:
s = "programming"; target character = 'g'.


### Question 3:
s = "hello".


## 7. Output

### Question 1:
```text
Vowels: 3
```


### Question 2:
```text
Count of g: 2
```


### Question 3:
```text
0: h
1: e
2: l
3: l
4: o
```

**Result:** All three Java programs were successfully written and executed to demonstrate character traversal, vowel counting, and character occurrence counting.
