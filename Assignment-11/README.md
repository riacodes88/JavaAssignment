# Assignment 11: Sorting Arrays Using Bubble Sort and Selection Sort

## 1. Experiment Title

Sorting Arrays Using Bubble Sort and Selection Sort in Java.

## 2. Aim

To write Java programs to sort arrays in ascending order using Bubble Sort and Selection Sort, and count the swaps performed by Bubble Sort.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. Sorting arranges data in a particular order. Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order. Selection Sort repeatedly finds the smallest element in the unsorted part and places it at the beginning. A swap exchanges the values of two array positions using a temporary variable.


## 5. Algorithm / Procedure

### Question 1: Bubble Sort

1. Start the program.

2. Initialize the array with 5, 1, 4, 2, and 8.

3. Compare adjacent elements using nested loops.

4. Swap adjacent elements when the left element is greater than the right element.

5. Display the sorted array.

6. Stop the program.



### Question 2: Selection Sort

1. Start the program.

2. Initialize the array with 64, 25, 12, 22, and 11.

3. For each position, find the index of the smallest element in the remaining unsorted array.

4. Swap the smallest element with the element at the current position.

5. Display the sorted array.

6. Stop the program.



### Question 3: Counting Bubble Sort Swaps

1. Start the program.

2. Initialize the array with 5, 1, 4, 2, and 8 and set swaps to 0.

3. Perform Bubble Sort by comparing adjacent elements.

4. Whenever two elements are swapped, increment swaps.

5. Display the total number of swaps.

6. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
Array = {5, 1, 4, 2, 8}.


### Question 2:
Array = {64, 25, 12, 22, 11}.


### Question 3:
Array = {5, 1, 4, 2, 8}.


## 7. Output

### Question 1:
```text
Sorted: [1, 2, 4, 5, 8]
```


### Question 2:
```text
Sorted: [11, 12, 22, 25, 64]
```


### Question 3:
```text

```
