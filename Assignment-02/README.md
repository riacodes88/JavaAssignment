# Assignment 2: Conditional Statements and Loops

## 1. Experiment Title

Conditional Statements and Loops in Java.

## 2. Aim

To write Java programs using if-else and if-else-if statements to check even or odd numbers, assign grades, identify leap years, and calculate factorials using a loop.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. Conditional statements execute different blocks of code according to conditions. The if statement checks a condition, else if checks another condition, and else executes when earlier conditions are false. The modulus operator (%) checks divisibility. A leap year is divisible by 400, or divisible by 4 but not by 100. A for loop repeats a block of code, and factorial is the product of all positive integers up to a given number.


## 5. Algorithm / Procedure

### Question 1: Even or Odd Number

1. Start the program.

2. Initialize integer n with 27.

3. Check whether n % 2 is equal to 0.

4. Display whether the number is even or odd.

5. Stop the program.



### Question 2: Grade Calculation

1. Start the program.

2. Initialize marks with 83.

3. If marks are at least 90, display Grade A.

4. Otherwise, if marks are at least 75, display Grade B.

5. Otherwise, display Grade C.

6. Stop the program.



### Question 3: Leap Year Check

1. Start the program.

2. Initialize year with 2024.

3. Check whether the year is divisible by 400, or divisible by 4 but not by 100.

4. Display whether it is a leap year.

5. Stop the program.



### Question 4: Factorial Using a Loop

1. Start the program.

2. Initialize factorial with 1.

3. Use a for loop from 1 to 5 and multiply each value into factorial.

4. Display the factorial of 5.

5. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
n = 27.


### Question 2:
marks = 83.


### Question 3:
year = 2024.


### Question 4:
Number = 5 (used to calculate its factorial).


## 7. Output

### Question 1:
```text
27 is odd
```


### Question 2:
```text
Grade: B
```


### Question 3:
```text
Leap year
```


### Question 4:
```text
Factorial of 5 is 120
```
