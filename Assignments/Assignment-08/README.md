# Assignment 8: Two-Dimensional Arrays and Matrix Operations

## 1. Experiment Title

Two-Dimensional Arrays and Matrix Operations in Java.

## 2. Aim

To write Java programs to create and display a matrix, find the transpose of a matrix, and calculate the sum of each row.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. A two-dimensional array stores data in rows and columns. Each element is accessed using two indexes: row and column. Nested loops are commonly used to initialize and traverse matrices. The transpose of a matrix is formed by interchanging its row and column indexes. Row sums are calculated by adding all elements in each row.


## 5. Algorithm / Procedure

### Question 1: Creating and Displaying a Matrix

1. Start the program.

2. Create a 3 × 4 integer matrix.

3. Fill the matrix with values starting from 1 using nested loops.

4. Traverse and display all matrix elements row by row.

5. Stop the program.



### Question 2: Transpose of a Matrix

1. Start the program.

2. Initialize a 3 × 3 matrix with values 1 through 9.

3. Create another 3 × 3 matrix for the transpose.

4. Copy each element from position [i][j] to [j][i].

5. Display the transposed matrix.

6. Stop the program.



### Question 3: Sum of Each Matrix Row

1. Start the program.

2. Initialize a 3 × 3 matrix with values 1 through 9.

3. For each row, initialize sum to 0.

4. Add all elements of that row to sum.

5. Display the sum of each row.

6. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
A 3 × 4 matrix is filled sequentially with values 1 to 12.


### Question 2:
Matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}.


### Question 3:
Matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}.
