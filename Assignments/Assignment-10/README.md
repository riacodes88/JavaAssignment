# Assignment 10: Switch Statements and ArrayList Operations

## 1. Experiment Title

Switch Statements and ArrayList Operations in Java.

## 2. Aim

To write Java programs using a switch statement to display a day name and using ArrayList to add, access, update, remove, and display elements.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. The switch statement selects a block of code based on the value of an expression. The break statement exits a switch case. ArrayList is a resizable collection in Java provided by java.util. It supports operations such as add(), get(), set(), remove(), and size(). ArrayList indexes start at 0.


## 5. Algorithm / Procedure

### Question 1: Displaying a Day Using Switch

1. Start the program.

2. Initialize day with 3.

3. Use a switch statement to match the day value with a case.

4. Display the corresponding day name or an invalid-day message.

5. Stop the program.



### Question 2: ArrayList Creation and Access

1. Start the program.

2. Create an ArrayList of integers.

3. Add 10, 20, 30, and 40 to the list.

4. Display the list, its size, and the element at index 2.

5. Stop the program.



### Question 3: Updating and Removing ArrayList Elements

1. Start the program.

2. Create an ArrayList and add 10, 20, 30, and 40.

3. Update the element at index 1 to 25 using set().

4. Remove the element at index 3 using remove().

5. Display the updated list and its size.

6. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
day = 3.


### Question 2:
List elements = 10, 20, 30, 40.


### Question 3:
Initial list = 10, 20, 30, 40; update index 1 to 25; remove index 3.


## 7. Output

### Question 1:
```text
Wednesday
```


### Question 2:
```text
[10, 20, 30, 40]
Size: 4
Item at index 2: 30
```


### Question 3:
```text
[10, 25, 30]
Size: 3
```

**Result:** All three Java programs were successfully written and executed to demonstrate switch statements and common ArrayList operations.
