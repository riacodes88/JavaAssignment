# Assignment 5: Array Basics and Traversal

## 1. Experiment Title

Array Basics and Traversal in Java.

## 2. Aim

To write Java programs to access array elements using indexes, calculate the sum and largest element of an array, and count elements greater than a specified value.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. An array stores multiple values of the same data type in a single variable. Array elements are accessed using zero-based indexes. The length property gives the number of elements. A for loop can traverse an array using indexes, while an enhanced for loop visits each element directly. A running sum, largest value, or count can be maintained while traversing an array.


## 5. Algorithm / Procedure

### Question 1: Displaying Array Elements with Index

1. Start the program.

2. Initialize the integer array with 3, 4, and 5.

3. Traverse the array using an index-based for loop.

4. Display each index and its corresponding value.

5. Stop the program.



### Question 2: Sum and Largest Element

1. Start the program.

2. Initialize the array with 12, 45, 7, 33, and 21.

3. Initialize sum to 0 and largest with the first array element.

4. Traverse the array and update the sum and largest value.

5. Display the sum and largest value.

6. Stop the program.



### Question 3: Counting Elements Greater Than 10

1. Start the program.

2. Initialize the array with 5, 12, 2, 14, and 7.

3. Initialize count to 0.

4. Traverse the array and increment count whenever an element is greater than 10.

5. Display the count.

6. Stop the program.



## 6. Input

The following values are used in the experiment:


### Question 1:
Array = {3, 4, 5}.


### Question 2:
Array = {12, 45, 7, 33, 21}.


### Question 3:
Array = {5, 12, 2, 14, 7}; comparison value = 10.
