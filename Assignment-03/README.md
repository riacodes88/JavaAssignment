# Assignment 3: Pattern Printing Using Nested Loops

## 1. Experiment Title

Pattern Printing Using Nested Loops in Java.

## 2. Aim

To write Java programs using nested for loops to print a square star pattern, an increasing star triangle, an increasing number triangle, and a decreasing star triangle.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE / Text Editor: Visual Studio Code (VS Code)
- Java Extension Pack for VS Code

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:


1. Loops execute a block of statements repeatedly. A for loop is useful when the number of iterations is known. Nested loops place one loop inside another. The outer loop controls the rows, while the inner loop controls the characters or numbers printed in each row. System.out.print() prints on the same line, whereas System.out.println() moves to the next line.


## 5. Algorithm / Procedure

### Question 1: Square Star Pattern

1. Start the program.

2. Use an outer for loop to repeat four rows.

3. Inside it, use an inner for loop to print four asterisks in each row.

4. Move to the next line after each row.

5. Stop the program.



### Question 2: Increasing Star Triangle

1. Start the program.

2. Use an outer for loop for rows 1 through 4.

3. For each row, use an inner loop to print asterisks equal to the row number.

4. Move to the next line after each row.

5. Stop the program.



### Question 3: Increasing Number Triangle

1. Start the program.

2. Use an outer for loop for rows 1 through 4.

3. For each row, print numbers from 1 up to the current row number.

4. Move to the next line after each row.

5. Stop the program.



### Question 4: Decreasing Star Triangle

1. Start the program.

2. Use an outer for loop from row 4 down to row 1.

3. For each row, print asterisks equal to the current row number.

4. Move to the next line after each row.

5. Stop the program.
